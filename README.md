# Forja de Mundos

Creador y gestor de universos de rol para el máster. Independiente de sistema, en español, sin instalación.

**Probarlo:** https://xesco-tejedor.github.io/Forja-de-Mundos/

- Genera un universo coherente por etapas a partir de una premisa y unos ajustes (tono, magia, tecnología, crudeza, escala, temas): mundo, lugares, culturas, reglas, facciones, historia, PNJ, conflictos, ganchos y guía del máster.
- Todo es editable. Bloquea (🔒) lo que te guste para que no se regenere; regenera o ajusta con una instrucción cualquier elemento.
- Relaciones entre elementos y comprobador de coherencia (automático y con IA).
- Gestor de campaña: sesiones, misiones y seguimiento de PNJ, lugares y facciones.
- Banda sonora original generada en directo con WebAudio: exploración, taberna, tensión, batalla, misterio y victoria solemne, con fundidos y adaptación al tono del universo.
- Exporta a PDF (A4), Markdown y JSON; importa JSON.
- Los datos se guardan solo en el navegador (localStorage). La IA usa un servidor intermedio; no hay claves en este repositorio.
